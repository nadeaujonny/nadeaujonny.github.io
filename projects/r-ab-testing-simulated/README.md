# A/B Testing & Experimentation in R (Simulated SaaS Onboarding Experiment)

## Overview

This portfolio project demonstrates a comprehensive A/B testing analysis workflow using R. The project analyzes a simulated SaaS onboarding experiment where we test different onboarding flows to improve user conversion and revenue. Through this analysis, we cover statistical testing, power analysis, regression adjustment, heterogeneous treatment effects, and rigorous quality assurance checks including Sample Ratio Mismatch (SRM) detection and covariate balance verification.

## How to Run

Follow these steps to reproduce the complete analysis:

1. **Set up the project environment**
   - Open the R project file (if you've created an `.Rproj` file) or manually set your working directory to `r-ab-testing-simulated/`
   - Ensure you have R version 4.0 or higher installed

2. **Install and load required packages**
   ```r
   source("requirements.R")
   ```
   This will automatically install (if missing) and load all necessary packages: tidyverse, infer, broom, patchwork, gt, lmtest, sandwich, pwr, and ggeffects.

3. **Generate the simulated dataset**
   ```r
   source("R/00_generate_data.R")
   ```
   This creates the experimental dataset and saves it as a CSV file in `data/raw/`

4. **Run the analysis scripts in order**
   ```r
   source("R/01_qc_srm.R")              # Quality checks & SRM detection
   source("R/02_primary_metric.R")       # Primary metric analysis (conversion)
   source("R/03_secondary_guardrails.R") # Secondary metrics & guardrails
   source("R/04_bootstrap_permutation.R")# Non-parametric inference methods
   source("R/05_regression_adjusted.R")  # CUPED/regression-adjusted estimates
   source("R/06_power_mde.R")            # Power analysis & MDE calculations
   ```

5. **Generate the final report**
   - Open `reports/ab_test_report.Rmd` in RStudio
   - Knit to HTML to generate the comprehensive analysis report
   - The rendered HTML will be saved in the `reports/` folder

### Folder Descriptions

- **data/raw/**: Contains the raw simulated experimental dataset generated by `00_generate_data.R`
- **data/processed/**: Stores any cleaned or transformed datasets created during analysis
- **R/**: All analysis scripts, numbered to indicate execution order
- **reports/**: RMarkdown files and their rendered HTML outputs
- **figures/**: Plot outputs saved from analysis scripts and the report
- **tables/**: Summary tables and statistics saved as CSV or RDS files

## Reproducibility

**Important:** This project uses a **simulated dataset** generated entirely from code. The data is not based on real user data. The simulation parameters (effect sizes, variance, sample size) are defined in `R/00_generate_data.R`, and all results are fully reproducible by running the scripts in order with the same random seed.

To ensure reproducibility:
- The data generation script uses a fixed random seed
- All analysis scripts source the same seed for consistency
- Package versions are managed through `requirements.R`
- Raw data is gitignored but can be regenerated at any time
