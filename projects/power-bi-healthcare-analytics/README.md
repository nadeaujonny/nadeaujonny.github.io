# Power BI Project: Healthcare Analytics Dashboard

This folder contains the project assets for the **Healthcare Analytics Dashboard** Power BI portfolio project. Add your `.pbix` workbook, datasets, and supporting documentation here as the project matures.

## Suggested structure

- `workbook/` → Power BI Desktop file (`.pbix`)
- `data/` → Raw/processed datasets and data dictionary
- `images/` → Dashboard screenshots and annotated visuals for the portfolio page

## Notes

This project page is documented in `index.md`. As you publish dashboards, drop screenshots into `images/` and reference them in the page.
